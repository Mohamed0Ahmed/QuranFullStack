# Sol/Codex Workspace Router

The user's explicit request defines the work. Current code is implementation truth.

## Native routing

1. Backend paths route to `Backend/AGENTS.md`.
2. Frontend paths under `Frontend/quran-dashboard-ui/` route to
   `Frontend/quran-dashboard-ui/AGENTS.md`.
3. Load only the structure source needed for the files being placed or moved.

## Project Skills

Project Skills are opt-in. Invoke Spec Kit, Test Guard, performance reviews, dependency audits,
deployment smoke, PR preparation, or cleanup Skills only when the user explicitly names the Skill
or asks to use that workflow. A generic request for a plan, implementation, review, test, or check
does not invoke Spec Kit or Test Guard.

Operational READMEs are references for their named commands and tools; they do not define the
development workflow.
