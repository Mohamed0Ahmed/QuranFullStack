# Quran Dashboard Structure Constitution

This constitution applies only when the user explicitly invokes a Spec Kit workflow.

## Structure

- Backend placement and layer boundaries are described by
  `Backend/.architecture/BACKEND_STRUCTURE.md` and
  `Backend/.architecture/CLEAN_ARCHITECTURE.md`.
- Frontend placement is described by
  `Frontend/quran-dashboard-ui/.architecture/FRONTEND_STRUCTURE.md`.
- Current code is implementation truth.
- The user's explicit scope and decisions control the requested work.

## Governance

This document defines structure only. It does not select tests, reviews, plans, Git operations,
deployment steps, or delivery gates.
